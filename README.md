## 🌊 Overview

Ithaca is an interactive, Odyssey-inspired website that transforms my journey into software engineering into a digital retelling of one of the most enduring stories in Greek mythology.

Inspired by Homer's *The Odyssey*, the experience follows the metaphorical voyage of an aspiring software engineer: from the first spark of curiosity to navigating unfamiliar technologies, overcoming technical challenges, experimenting with new ideas, and working toward a destination that is still evolving.

Rather than creating another conventional developer portfolio, I wanted to build something that communicates the experience of learning, creating, failing, experimenting, and growing through an entirely different visual language.

The result is an ancient-inspired digital chronicle featuring animated maritime scenery, layered visual effects, parchment-inspired storytelling, and a collection of chapters documenting my engineering journey.

## 🏛️ Why I Built This

I created this project for the **United Falls Web Challenge 2026**, where I wanted to explore how frontend development could be used as a storytelling medium rather than simply a way to display information.

Most developer portfolios follow a familiar structure: an introduction, a collection of projects, a skills section, and contact information.

I wanted to challenge that convention.

The Odyssey provided an interesting parallel to software engineering. Odysseus encounters unfamiliar environments, unexpected obstacles, difficult decisions, and opportunities to learn throughout his journey.

Software engineering feels remarkably similar.

Every unfamiliar framework is another island to explore. Every debugging session is an unexpected obstacle. Every completed project is another milestone along the way.

**Ithaca represents the destination, but the journey is what makes the story worth telling.**

## 🧭 Challenges I Faced

Building this experience involved more than simply creating an attractive interface. Some of the most interesting challenges came from balancing visual storytelling with a functional browsing experience.

### 1. Combining Multiple Animation Layers

The opening scene uses multiple visual elements, including parallax layers, animated scenery, atmospheric effects, and a moving maritime environment.

Making these elements coexist without creating visual inconsistencies required careful attention to positioning, layering, and transitions.

### 2. Managing Scroll Behavior

One of the biggest challenges was making the transition between the animated voyage and the parchment-inspired content feel natural.

Initially, elements from the opening scene remained visible behind the written sections, creating unwanted visual overlap.

I refined the scrolling behavior and visibility transitions to create a cleaner separation between the two experiences.

### 3. Maintaining Visual Consistency

The maritime opening and the ancient manuscript sections have different visual characteristics.

I wanted them to feel like parts of the same story rather than two unrelated website templates.

Typography, color palettes, decorative details, and transitions helped establish a consistent visual identity.

### 4. Balancing Creativity and Usability

A highly animated website can easily become difficult to navigate.

I wanted the visual experience to remain engaging without making the content difficult to read or the navigation unnecessarily complicated.

This meant considering transition timing, readability, section spacing, and the overall browsing experience.

## 💻 Getting Started

One of the advantages of this project is that it does not require a complicated development environment.

### Prerequisites

- A modern web browser.
- A code editor (Visual Studio Code recommended).

### Installation

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/ithaca-developers-odyssey.git
```

Navigate into the project:

```bash
cd ithaca-developers-odyssey
```

Open the website:

```text
odyssey/dist/index.html
```

You can also open the HTML file directly in your browser.

No npm installation, framework setup, or compilation process is required.
